Sandscale——免费的 Agent 云沙箱：每月 100 小时 awake 算力，暂停闲置不计费

给编程 Agent 用的云端沙箱：代码在隔离的微虚拟机里跑，暂停与工具调用间隙不计费，免费档每月有 100 小时可用额度。

有效 11-26 · 晚 高热度 原始来源 ↗

Sandscale 是给 Claude Code、Codex 这类编程 Agent 准备的云端算力：沙箱、工作区与构建机都跑在它家的机器上，通过一个接口调用，不用自己搭服务器。核心是 Firecracker 微虚拟机，每个 Agent 跑在独立的盒子里，可以执行命令、传文件、看日志、打快照，暂停之后再恢复。

先看这几点

  • 免费档每月 100 awake vCPU-hours，同时最多开 3 个盒子，配 5GB 存储与 1 个工作区
  • 只按“醒着”的时间计费，暂停与工具调用之间的闲置时间免费
  • 单个盒子最多 2 vCPU，单次会话最长 4 小时
  • 每个盒子有独立内核，密钥放在 Vault 里不进提示词，每次操作都进审计日志

它值得看的地方在于计费方式：Agent 干活是一阵一阵的，思考、等审批、等人回话时机器都在空转，按传统方式租云主机就是在为空转付钱。Sandscale 只算盒子醒着的时间，暂停就停表，这对“让 Agent 半夜自己跑测试”的场景很友好。视频里把这一点讲清，观众立刻能算出自己的账。

适合经常让 Agent 跑代码、跑测试、改项目的人，也适合想在视频里演示 Agent 工作流的创作者。自己电脑配置一般、又不想把密钥和本地文件交给 Agent 的人，尤其可以先拿免费档试一次。

怎么拍成视频

  1. 标题方向：免费云沙箱每月白送 100 小时算力，Agent 跑代码不用自己电脑
  2. 先注册免费档，开一个盒子让 Claude Code 修一个真实的小问题，全程录屏
  3. 中段暂停盒子，展示计费停在原地，再恢复继续跑
  4. 打开仪表盘看审计日志与 Vault，讲清密钥没有进提示词
  5. 收尾前复核免费档额度与超量规则，说明超量不自动扣费、新盒子要等下月
别忽略这一条

免费档超量不会自动扣费，但新盒子要等到下月才能开；单盒子 2 vCPU、单次 4 小时的上限，做长任务要先拆步骤。另外目前机房在美国，欧洲节点还在准备中，拍之前先核对官网的最新口径。
