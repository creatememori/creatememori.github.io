airoom——免费开源的 Claude Code 指挥室：多会话一屏管，逐条批命令、还能让 Agent 自己测应用

免费开源的 Claude Code 指挥室：多个会话一屏管理，状态一眼可见，还能组队并行干活、让 Agent 自己开浏览器测应用，全程本机运行。

有效 11-28 · 晚 高热度 原始来源 ↗

airoom 是一个免费开源的 Claude Code 指挥室，Apache 2.0 协议，11 月 24 日登上 Product Hunt，11 月 28 日冲到当日第 9。它的界面像一间间房：每个项目一间房，每个会话一张桌，屏幕颜色一眼就能看出谁在干活、谁在等你、谁卡住了。点一张桌子就能跟那个 Agent 聊天、逐条批命令、一键叫停；还能组一支小队并行干活，每个成员各占一个 git worktree；跑顺的任务可以存成 Playbook 下次复用；内置浏览器让 Agent 自己打开应用点一点、测一测。

先看这几点

  • 每个项目一间房、每个会话一张桌，状态颜色一眼可见
  • 点桌子聊天、逐条批命令、一键叫停
  • 可组小队并行干活，各占一个 git worktree；任务可存成 Playbook 复用
  • 内置浏览器，Agent 可自己打开应用测试
  • 完全免费、无账号、无遥测，全程本机运行

多会话并行是 Claude Code 重度用户的常态，但窗口一切换就容易乱：哪个在跑、哪个在等确认、哪个卡住了，全靠记忆。airoom 把这层状态做成了一张看板，管理成本一下子降了下来；Playbook 和 worktree 并行则让“跑顺的流程”能沉淀下来复用。适合同时开多个 Agent 会话做开发、或想把重复任务流程化的开发者。

对同时带几个项目的开发者来说，这类工具省的是切换成本：不用在多个终端窗口之间来回找，哪个会话在等确认、哪个卡住了，看一眼颜色就知道。Playbook 则适合把重复流程固定下来，下次遇到同类任务直接复用，不用每次重新指挥。

怎么用

  1. 安装 airoom，为每个项目开一间房、为每个会话开一张桌
  2. 看桌子颜色判断状态，点桌子聊天、批命令或一键叫停
  3. 把跑顺的任务存成 Playbook，需要并行时组小队、各占一个 worktree
平台与费用

完全免费、无账号、无遥测，全程本机；Mac 已有正式版，Windows 目前为 beta；模型走你自己的 Claude 订阅，airoom 本身不另收费。
