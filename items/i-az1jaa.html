OpenGame——把 20+ 编程 Agent 变成游戏工作室：25 个可玩模板，小游戏直发微信/抖音/TikTok

开源游戏开发平台，一句指令把 20 多个本地编程 Agent 接进本地工作室，25 个 HTML5 模板可玩可改，成品能发到微信、抖音与 TikTok。

有效 11-27 · 中午 高热度 原始来源 ↗

11 月 25 日创建、上线即登 GitHub 日榜前三：OpenGame 是开源游戏开发平台（Apache-2.0），一句指令把 Claude Code、Codex、DeepSeek 等 20 多个本地编程 Agent 接进本地 Game Studio。25 个 HTML5 / Three.js 模板（3D 竞速、体素射击、像素平台等）可玩可改，成品可发微信、抖音、TikTok、Telegram 与 itch.io。

先看这几点

  • 接 20 多个本地编程 Agent，一句指令进工作室
  • 25 个 HTML5 / Three.js 模板，可玩可改
  • 成品直发微信、抖音、TikTok、Telegram、itch.io
  • Apache-2.0 开源，上线两天 800+ 星

它解决的是“AI 写小游戏”最后一公里：以前 Agent 写完代码，你还得自己搭页面、处理发布；OpenGame 把 Agent、工作室与发布通道放在同一个地方，模板先给你一个能玩的底子，Agent 在这个底子上改，改完直接发。做小游戏验证玩法、做活动页、给孩子做个能玩的作业，都用得上。

适合想用 AI 快速做小游戏的独立开发者、做互动内容的运营，以及想让孩子边玩边学编程的家长。模板是 HTML5，改起来不需要游戏引擎基础。

怎么用

  1. 装好 Node 22.18 以上，从源码启动本地工作室
  2. 接一个本地编程 Agent（Claude Code、Codex 或 DeepSeek 等）
  3. 挑一个模板开玩，一句指令让 Agent 改玩法，改好后选渠道发布
别忽略这一条

工作室目前需从源码运行，没有一键安装包；模板素材首次使用要联网下载，离线环境第一次打开会卡住。

OpenGame 的模板与发布很全：25 个 HTML5、Three.js 模板，3D 竞速、体素射击、像素平台；成品发微信、抖音、TikTok、Telegram、itch.io。工作室需从源码运行（Node 22.18+）；模板素材首次使用要联网下载，离线环境先备好。
