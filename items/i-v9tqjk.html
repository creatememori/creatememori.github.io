做 React 项目想加动效，常常是东拼西凑找组件，风格还不统一。AvaraUI 是 11 月 7 日在 Product Hunt 上线的组件库：190 多个免费 React 组件与 24 个以上网站区块，3D 位移悬停、物理动画、卡片扇形展开等交互效果都带实时预览，shadcn CLI 一条命令就能装进项目。

它的卖点是动效组件化：效果不是写在某个演示页里的孤例，而是可以直接装进项目的组件，风格基于 shadcn，装好就能用。对做落地页、产品站、仪表盘的人来说，这类库省的是从零写动效的时间：先看实时预览挑效果，再一条命令装进项目，改颜色改文案即可。

先看这几点

  • 190 多个免费 React 组件，24 个以上网站区块
  • 3D 位移悬停、物理动画、卡片扇形展开等效果
  • 全部带实时预览
  • shadcn CLI 一键安装，还带 MCP，AI 编程助手可直接调用

怎么用

  1. 打开官网按效果分类浏览，实时预览挑中意的组件
  2. 用 shadcn CLI 一条命令装进项目
  3. 按项目风格调颜色与文案
  4. 需要时让 AI 编程助手经 MCP 直接调用组件

适合谁：做 React 落地页、产品站、仪表盘的开发者最值得收藏，尤其是用 shadcn 体系的项目。动效组件最怕的是演示好看、装进项目却水土不服；AvaraUI 的组件直接基于 shadcn，190 多个组件与 24 个以上区块都有实时预览，挑中效果再一条命令装进项目，风格天然统一。3D 位移悬停、物理动画、卡片扇形展开这类效果，单独写要花不少时间，直接用组件等于把别人的调试成本省掉了。还带 MCP，AI 编程助手可以直接调用组件，边写边搭页面更快。全部免费开源，只有一个前置条件：需要 Tailwind CSS v4，旧项目先确认版本再装。

注意

全部免费开源。但需要 Tailwind CSS v4，旧项目升级 Tailwind 之前先确认版本兼容。
