TypeMotion.Art——浏览器动态文字工作室：模板调动效，视频标题片头即做即看

浏览器里的动态文字工作室：选模板、调动效、实时预览，做视频标题、片头与动效字幕，导出 MP4、透明 WebM 与 MOV、GIF 与 PNG。

有效 11-26 · 晚 高热度 原始来源 ↗

TypeMotion.Art 在 11 月 25 日上线，是浏览器里的动态文字工作室，专门做一件事：让文字动起来。选一个模板，改文字、调动效，实时预览效果，做视频标题、片头与动效字幕。导出支持 MP4、透明 WebM 与 MOV、GIF 与 PNG，透明通道可以直接叠在剪辑时间线上。

先看这几点

  • 浏览器里选模板、调动效、实时预览
  • 做视频标题、片头与动效字幕
  • 导出 MP4、透明 WebM 与 MOV、GIF、PNG
  • 免费档可编辑预览，导不出成片
  • 导出需 Day Pass 4.99 美元或订阅 9.99 美元每月

标题与片头是视频里最容易看出敷衍的地方，但也是最不值得为此开一套动效软件的地方。TypeMotion 把这件事收成一个轻工具：不用学关键帧，不用装插件，调好字体、速度与配色就能出一段能直接用的标题动画。透明 WebM 与 MOV 的支持很关键，动效字幕可以直接叠在画面上，不用再抠绿幕。

适合短视频创作者、教程与课程制作者、做演示视频的人：经常需要标题卡、开场提问、动效字幕，但不想为几秒钟的文字动画打开 After Effects。只做静态封面的人用不上它。

怎么用

  1. 打开 typing-animation-maker 页面，选一个模板
  2. 换上自己的文字，调打字速度、字体、颜色与画幅
  3. 完整回放一遍，检查可读性与出入场时机
  4. 需要竖屏或方形时切换比例再检查一次
  5. 买 Day Pass 或订阅后选格式导出，透明背景选 WebM 或 MOV
免费档导不出成片

免费档只能编辑与预览，导不出成片：导出要 Day Pass 4.99 美元或订阅 9.99 美元每月，临时用一次买 Day Pass 更划算。透明 MOV 限 1080p、30 帧、8 秒，做长片头前先确认时长够不够；导出的是渲染好的媒体文件，不是可编辑的工程文件。

先免费把标题调到满意再决定要不要付费导出：预览不花钱，判断标准就是回放时文字节奏是否舒服。如果一周只做一两支视频，Day Pass 比订阅划算得多。
