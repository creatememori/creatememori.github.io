Tokens by UI Colors 是一个免费的设计 token 游乐场，11 月 9 日上线，24 日更新。配色、字体、间距、圆角、阴影这些视觉要素可以在一个地方一次调出来，调完直接导出 CSS 变量，或者导出一份 DESIGN.md 喂给 AI 编程助手。

设计 token 的价值在于一致：颜色、间距、圆角各调各的，页面很容易越做越散。这个工具把它们收进同一套视觉语言里，预设可以快速换方向，真 UI 示例实时预览，改一个值马上能看到整套界面的变化。对没有专职设计师的小团队来说，它等于把设计系统最基础的一层先搭好了。

先看这几点

  • 配色、字体、间距、圆角、阴影一次调出整套视觉语言
  • 预设快速换方向，真 UI 示例实时预览
  • 导出 CSS 变量或 DESIGN.md
  • DESIGN.md 可直接喂给 AI 编程助手

怎么用

  1. 打开 Tokens by UI Colors 的页面
  2. 选一个预设方向，或从头调配色与字体
  3. 在真 UI 示例里实时看效果，微调间距与圆角
  4. 导出 CSS 变量进项目，或导出 DESIGN.md 交给 AI 编程助手
价格

免费使用；Pro 4.95 美元/月，按需决定是否升级。

适合独立开发者、小团队前端，以及用 AI 编程助手做界面的创作者。提醒一点：导出的 token 只是起点，真实项目的视觉语言还需要结合品牌与内容再打磨；DESIGN.md 喂给 AI 助手后，也要检查生成代码是否真的按 token 落地，别只看文档写得漂亮。这类工具还有一个容易被忽略的用法：把它当作与 AI 编程助手沟通的桥梁。先在游乐场里把视觉语言定下来，导出 DESIGN.md，再让 AI 按这份文档生成界面，比口头描述颜色与间距要可靠得多。改设计时也一样，先在工具里改 token，再重新导出，避免设计与代码各改各的。先定一套 token 再开始写界面，比边写边调要省事得多，也更容易保持一致。
