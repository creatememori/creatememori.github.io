explainroo——免费开源，AI 给你拍讲解视频：本地配音、逐词字幕，不用 API Key

开源免费的讲解视频工具：把主题交给 Claude Code 或 Codex，就能得到带本地配音、逐词字幕与运镜的 MP4，连自己的录音也能按词剪。

有效 11-27 · 晚 高热度 原始来源 ↗

explainroo 是 GitHub 上的一个 MIT 开源项目，思路很直接：你给一个主题，它调用 Claude Code 或 Codex 写脚本、做分镜，再用本地语音把讲解读出来，用 Whisper 对齐每一个词的时间戳，最后渲染成带运镜的 MP4。整个过程不用 API Key，配音在本地完成，成片自带字幕、章节与封面图。

先看这几点

  • MIT 开源，GitHub 可直接拉取
  • 接 Claude Code 或 Codex，输个主题就出 MP4
  • 本地配音、逐词字幕、带运镜
  • 还能按词剪自己的录音

它值得留意的地方在于把讲解视频拆成了一条可复用的流程：脚本、分镜、配音、字幕、渲染，每一步都有明确的输入输出。对做知识类视频的人来说，最大的成本往往不是拍，而是把一句话主题变成一段结构完整的讲解。explainroo 把这段路打通了，而且配音和字幕都在本地做，不用把素材传到云端，也不用为调用次数付费。

按词剪自己的录音这个功能也很实用：录好的口播如果某句话说错了，可以直接按词定位修改，不用整段重录。适合做科普、教程与知识讲解的创作者，也适合想批量出讲解视频、但不想每次都从头搭流程的人。拍之前先自己跑通一次，确认成片效果再决定怎么讲。

怎么拍这期视频

  1. 先讲建议标题的切入点：给 AI 一个主题，它直接拍出带配音的讲解视频
  2. 实拍从 GitHub 拉下 explainroo、接上 Claude Code 或 Codex 的过程
  3. 输入一个主题，展示从脚本到成片的完整链路
  4. 特写逐词字幕与运镜效果，再演示按词剪一段自己的录音
  5. 结尾说明水印开关与高级配音的 Key 要求
注意

默认成片带小水印，可以关掉；想要 ElevenLabs 这类高级配音，需要自备 Key。演示时先把水印开关的位置讲清楚，别让观众以为水印去不掉。
