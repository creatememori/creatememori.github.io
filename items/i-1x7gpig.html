RoboFont——为 macOS 写的字体编辑器

为 macOS 写的字体编辑器：Python 从头写起、UFO3 原生格式，几十个开源扩展随装随用，画字、间距与脚本自动化能串成一条工作流。

有效 11-27 · 中午 中热度 原始来源 ↗

RoboFont 是为 macOS 写的字体编辑器：Python 从头写起、UFO3 原生格式，几十个开源扩展随装随用。字体设计师想把画字、间距、脚本自动化串成一条工作流，看它就够了。

先看这几点

  • Python 从头写起，扩展随装随用
  • UFO3 原生格式，开放可互通
  • 几十个开源扩展覆盖常见流程
  • 画字、间距、脚本自动化串成工作流

RoboFont 的定位很明确：给认真做字体的设计师一个能编程的工作台。画字是基础，真正的差别在扩展与脚本：批量调间距、自动生成字形变体、跑自己的检查脚本，都能接进来。对做字体家族、要长期维护一套字库的人来说，这种可编程性比界面花哨重要得多。

适合专业字体设计师与字体工程师，尤其适合已经在用 UFO 工作流、或想把重复劳动写成脚本的人。macOS 专属，Windows 用户需要另找工具。

怎么用

  1. 在 macOS 上装好 RoboFont，熟悉画字与间距界面
  2. 按需装开源扩展，补齐自己工作流缺的环节
  3. 把重复操作写成 Python 脚本，沉淀成自己的流程
提示

macOS 专属；UFO3 是开放格式，文件能在不同工具间互通，不会被单一软件锁死。

RoboFont 的工作流是：Python 从头写起，UFO3 原生格式，几十个开源扩展；画字、间距、脚本自动化能串成一条工作流。macOS 专属，适合认真做字体、愿意用脚本提效的设计师与字体作者。专业字体设计师常用的工具，学习成本不低，但自动化能力是它最大的优势。
