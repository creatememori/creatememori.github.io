animateicons——1500 个会动的 SVG 图标：React、Vue、Angular、原生 JS 通用，悬停点击都触发

1500 个手工调过的动画图标：悬停就播放，也能改成点击触发，React、Vue、Angular、原生 JS 各有包，还能让 Agent 帮你挑。

有效 11-28 · 早 高热度 原始来源 ↗

animateicons 是 1500 个免费开源的动画图标，基于 Motion 驱动。每个动画都手工调过，悬停默认播放，也可以改成点击触发，大小、颜色、时长都能调。React、Vue、Angular 与原生 JS 各有包，支持 Lucide 与 Hugeicons 两套造型，还能用 shadcn CLI 或 npx 单个复制进项目，走 MCP 让 Agent 帮你挑。MIT 开源，图标造型源自 Lucide 与 Hugeicons。

先看这几点

  • 1500 个免费开源动画图标，每个动画都手工调过。
  • 悬停默认播放，也可改成点击触发，大小、颜色、时长都能调。
  • React、Vue、Angular 与原生 JS 各有包，支持 Lucide 与 Hugeicons 两套造型。

图标动效最容易犯的错是“动了，但没调过”：时长不对、缓动生硬，反而显得廉价。animateicons 的卖点是每个动画都手工调过，拿来就能用，不用自己再调一遍曲线。1500 个的数量也够覆盖常见场景，按钮、导航、状态提示都有对应的动效。按需单个复制的方式很克制，只用几个图标时不用把整库搬进项目，包体积不会被拖大，图标数量多，先在站内按关键词筛一遍再决定用哪一套，免得逐个试花掉太多时间。

适合正在做界面细节、想给图标加一点反馈感的前端开发者，也适合用 shadcn 体系的项目。Lucide 与 Hugeicons 两套造型基本覆盖了主流审美，挑的时候按现有图标库选就行。要注意它解决的是图标这一层的动效，页面级的转场和复杂编排还得另找工具。挑的时候先对一下现有图标库的风格，混用两套造型会让界面看起来不统一；先从最常用的几个图标试起，效果满意再扩大范围。

怎么用

  1. 先按现有图标体系选造型：Lucide 或 Hugeicons。
  2. 用 shadcn CLI 或 npx 单个复制需要的图标进项目。
  3. 确认触发方式是悬停还是点击，再调大小、颜色与时长。
别忽略这一条

图标造型源自 Lucide 与 Hugeicons，商用前确认一次许可即可；另外动画图标虽小，也别在同一屏里全开，留一点克制。
