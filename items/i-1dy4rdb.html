Pushary Calls——错过 Agent 的提醒就直接打电话来：电话里说 yes/no 就能批，覆盖 13 种 Agent

编程 Agent 要你拍板却错过通知时，直接打电话来：电话里说 yes 或 no 就能批，覆盖 13 种 Agent。

有效 11-27 · 晚 高热度 原始来源 ↗

让编程 Agent 半夜跑任务，最怕它中途停下来等你拍板，而你刚好错过了通知。Pushary Calls 是 11 月 27 日登上 Product Hunt 的服务：Agent 要你拍板时先推通知，错过就直接打电话过来，电话里问清就说 yes 或 no，还能改指令。

它覆盖 Claude Code、Codex、ChatGPT、Gemini CLI 等 13 种 Agent，支持英、德、法、荷四种语言。对把长任务交给 Agent 跑的人来说，电话审批解决的是通知沉没的问题：消息可以漏看，来电很难错过，批复也不用再打开电脑，电话里说一句话就行。

先看这几点

  • 错过通知就直接打电话来审批
  • 电话里说 yes 或 no，还能改指令
  • 覆盖 13 种 Agent
  • 英、德、法、荷四种语言

怎么用

  1. 接入你用的 Agent，设置需要人工拍板的环节
  2. Agent 要拍板时先收通知
  3. 错过通知就接电话，在电话里批复或改指令
  4. 事后在记录里核对批复结果

适合谁：让编程 Agent 跑长任务的人最用得上，尤其是半夜挂任务、第二天早上才看结果的开发者。Agent 跑长任务时常常中途停下来等拍板，通知一沉没，任务就卡在那里等到天亮；Pushary Calls 的做法是先推通知，错过就直接打电话过来，电话里问清就说 yes 或 no，还能改指令，不用再打开电脑。覆盖 Claude Code、Codex、ChatGPT、Gemini CLI 等 13 种 Agent，英、德、法、荷四语，多数人用英语就够了。要注意的是 3 天试用需要绑卡，之后每月 9.99 美元，含每月 10 分钟通话与 5000 条通知，到期不取消会自动扣费，试用前先想好要不要续。电话审批的记录要留好，批了什么、改了什么指令，事后能在记录里核对；电话里说不清的复杂改动，还是回电脑上改完再让 Agent 继续跑。
