Periscope——把任何重复工作变成一个 API：描述一次任务，Agent 在云端专属桌面上替你干完

把重复工作变成一个 API：描述一次任务，Agent 在云端专属桌面上替你操作没有 API 的 Windows 程序与网站，结果按你定的格式返回。

有效 11-27 · 晚 高热度 原始来源 ↗

Periscope 在 11 月 27 日登上 Product Hunt。用法是：说清任务与要用的软件，Agent 在云端自己的桌面上操作，包括那些没有 API 的 Windows 程序与网站。你按 REST 或 MCP 调用它的接口，结果按你预先定好的格式返回。需要登录或者需要你拍板的时候，它会先停下来等你。

先看这几点

  • Agent 在云端专属桌面上操作，包括没有 API 的 Windows 程序与网站
  • 按 REST 或 MCP 调用接口，结果按你定的格式返回
  • 需要登录或拍板时先停下来等你
  • 免费档 0 美元、1 个 Agent、每周 10 次运行，免绑卡

它解决的是自动化里最常见的死角：很多日常软件根本没有 API，常规的自动化工具够不着。Periscope 的做法是让 Agent 直接在桌面上操作，把操作结果再包成 API 交给你。对个人用户来说，每周 10 次的免费额度够试清楚它到底能不能接手自己的重复任务；对想把它接进工作流的人来说，REST 与 MCP 两种调用方式都给了，接入成本不高。

适合的场景是流程固定、重复出现、但目标软件没有接口的任务，比如定期从某个桌面程序里导出数据，或者在某个网站上走一套固定操作。不适合的场景是需要频繁人工判断、或者对实时性要求很高的操作——Agent 操作桌面本身就比直接调接口慢，遇到登录与拍板还会停下来等你。先拿免费档验证场景，再决定要不要付费。

怎么用

  1. 先想清楚一个重复任务：目标是什么、用的软件是哪个
  2. 在 Periscope 里描述任务与软件，定好结果返回的格式
  3. 先用免费档跑几次，看 Agent 的操作是否符合预期
  4. 确认无误后再按 REST 或 MCP 把它接进自己的流程
  5. 遇到登录或拍板提示时及时处理，别让任务一直挂着
注意

免费档 0 美元、1 个 Agent、每周 10 次运行，免绑卡；Starter 20 美元/月。先拿免费档验证场景，再决定要不要付费。
