allomono 0.1——Allo 改成的等宽终端字体：输入 -> 与 => 自动变箭头且不占宽

Allo 改成的等宽终端字体：输入 -> 与 => 自动变成箭头且不占宽，专为代码与终端而生。

有效 11-27 · 晚 中热度 原始来源 ↗

allomono 0.1 是一款 11 月 26 日发布的等宽终端字体，由 Allo 改成。它有正、粗、斜、粗斜四款，共 996 个字符，含制表符。最有意思的细节是连字：输入 -> 与 => 会自动变成箭头，而且不占额外宽度，代码里的箭头读起来更顺。

终端字体好不好用，常常取决于这些小地方。箭头连字不占宽，意味着代码对齐不会被打乱；制表符齐全，表格与缩进显示才稳定。它为 Retina 屏幕绘制，普通屏幕也有 hinting，不同设备上的清晰度都有照顾。对天天盯着终端的人来说，字体顺眼，工作节奏也会顺一点。

先看这几点

  • 正、粗、斜、粗斜四款，996 字符含制表符
  • -> 与 => 自动变箭头，且不占宽
  • 为 Retina 绘制，普通屏有 hinting
  • OFL 1.1 免费商用

怎么用

  1. 打开 GitHub 的 sebinsua/allomono 仓库
  2. 下载 fonts/ 文件夹里的字体文件
  3. 在系统里安装四款字体
  4. 在终端或编辑器里把等宽字体设为 allomono
安装注意

刚发布 v0.1，暂无正式 release，需要直接下载 fonts/ 文件夹安装；版本很新，遇到显示问题可以先回退到原来的终端字体。

适合程序员、终端重度用户，以及喜欢折腾等宽字体的人。提醒一点：连字效果依赖编辑器与终端的支持，如果你的工具不支持连字，箭头就不会变，装之前先确认自己的环境能不能用上这个特性。等宽字体这件事，换上去的第一天可能没感觉，连续用一周才分得出好坏：箭头连字顺不顺、制表符齐不齐、长时间看累不累，都是用出来的结论。建议装好后直接当作主力字体用几天，再决定留不留，单纯看字样表很难判断。另外，996 个字符的覆盖面也要留意，自己的代码里如果有特殊符号，先确认都能正常显示。字体这种东西，看字样表不如直接用一周，合不合适用过才知道。
