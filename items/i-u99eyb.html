Nookdeck——旧手机变 Stream Deck：免费开源，手机浏览器开面板、不用装 App、不用账号

在电脑上跑一个小服务，抽屉里的旧手机或平板用浏览器打开，就变成一块能按快捷键、放音乐、看系统状态的触控面板。

有效 11-26 · 晚 高热度 原始来源 ↗

Nookdeck 是把旧手机变成 Stream Deck 的免费开源工具：在电脑上跑一个小服务，旧手机或平板用浏览器打开同一个局域网地址，就是一块触控面板。上面可以放快捷键、应用启动、媒体控制与宏按钮，还有实时显示系统状态、正在播放、天气与 Home Assistant 控制的动态卡片。

先看这几点

  • 免费 MIT 开源，手机端不用装 App、不用注册账号、不用经过云
  • 按钮覆盖快捷键、应用、媒体与宏，另有实时状态卡片
  • 能看 Claude 与 Codex 的用量，接得上 Home Assistant
  • 旧 iPhone 也能用，作者说卡在 iOS 12 的老机器照样打开面板

它值得拍，是因为“旧手机别扔”这个开头自带画面：抽屉里躺着的旧手机，几分钟后变成一块放在桌面的控制板。Stream Deck 本身不便宜，而 Nookdeck 的成本是零，观众看完就能照着做。拍的时候别只讲功能，把“按一下键灯就灭了”这种真实反应拍出来，比念参数管用。

适合桌上已经有两块屏幕、还总在找快捷键的人，适合家里接了 Home Assistant 的玩家，也适合手里有闲置旧手机、想让它重新上岗的观众。写代码时想顺手看 Agent 用量的人，也能把它当一块副屏。

怎么拍成视频

  1. 标题方向：旧手机别扔，免费开源变身 Stream Deck，浏览器开面板就能用
  2. 开场先亮旧手机和 Stream Deck 的价格对比，再亮 Nookdeck 是免费开源
  3. 在 Mac 上装好小服务，旧手机用浏览器打开面板，全程录屏
  4. 现场按一个键关灯或切歌，展示实时状态卡片与 Home Assistant 控制
  5. 收尾讲清两点限制：电脑端以 Mac 为主，Windows 版仍为实验性；macOS 首次启动要在系统设置点“仍要打开”
别忽略这一条

电脑端以 Mac 为主，Windows 版仍为实验性，Windows 用户拍前要先实测。macOS 构建还没有经过苹果公证，首次启动需在系统设置里点“仍要打开”。面板走局域网，出门在外连不上，别把它当远程控制用。
