MemoryWorks——给工程团队的公司记忆层：决策与事故都有出处，Agent 动手前先读简报

给工程团队的公司记忆层：决策与事故都有出处，Agent 动手前先读简报，旧决策被取代后仍留档可查。

有效 11-27 · 中午 高热度 原始来源 ↗

11 月 25 日登 Product Hunt：MemoryWorks 是工程组织的记忆层——从 GitHub、Slack、Drive、Notion、Teams 与文档里抓决策、上下文与 know-how，每个答案都带出处、可溯时间；通过 MCP 接 ChatGPT 与 Claude Code，Agent 动手改代码前先拿到一份“可执行、带条件执行、需审批”的简报，旧决策被新决策取代后仍留档可查。

先看这几点

  • 从 GitHub、Slack、Drive、Notion 抓决策与上下文
  • 每个答案都带出处、可溯时间
  • MCP 接 ChatGPT 与 Claude Code
  • Agent 动手前先拿简报：可执行、带条件、需审批

工程团队最贵的不是写代码，是“为什么当时这么定”没人记得。MemoryWorks 把散在 GitHub、Slack、Drive、Notion、Teams 与文档里的决策与 know-how 收到一处，每个答案带出处、可溯时间；Agent 动手改代码前，先拿到一份简报——可执行、带条件执行还是需审批，写得清清楚楚。旧决策被新决策取代后仍留档可查，不怕翻旧账。

适合工程团队、尤其适合多人协作、Agent 已经参与写代码的团队。开源 AGPL-3.0、免费；托管版据称有 3 个月免费试用（3 台设备、每月 5000 次 MCP 调用、免绑卡），以官网为准。

怎么用

  1. 接 GitHub、Slack、Drive、Notion、Teams 与文档
  2. 通过 MCP 接 ChatGPT 与 Claude Code
  3. Agent 动手改代码前先读简报，按可执行、带条件、需审批分流
提示

旧决策被新决策取代后仍留档可查；托管版试用口径以官网为准，3 个月免费试用、3 台设备、每月 5000 次 MCP 调用、免绑卡。
