DeskFleet——团队多机协同跑编程 Agent：同事能接手你的 Agent 会话、审 diff、批命令

团队多机协同跑编程 Agent：同事能接手你的 Agent 会话、审 diff、批命令，工具与 Agent 凭证留在干活的那台机器上。

有效 11-27 · 中午 高热度 原始来源 ↗

11 月 26 日登 Product Hunt 日榜第 10：DeskFleet 是给团队的编程 Agent 共享会话——Claude Code、Codex、Cursor 跑在代码所在的机器上，同事能从自己电脑加入同一会话、读上下文、审 diff、批准下一条命令或直接接管远程桌面；工具与 Agent 凭证留在干活的那台机器上。

先看这几点

  • 团队共享编程 Agent 会话
  • 同事能接手会话、审 diff、批命令
  • 可直接接管远程桌面
  • 工具与 Agent 凭证留在干活的机器上

一个人跑 Agent 是单机作战，团队跑 Agent 最大的麻烦是“接手”：同事想接着你的会话改，得先把上下文、凭证、环境全搬过去。DeskFleet 让 Agent 跑在代码所在的机器上，同事从自己电脑加入同一会话，读上下文、审 diff、批准下一条命令，甚至直接接管远程桌面；工具与 Agent 凭证留在干活的那台机器上，不用满天飞。

适合团队一起用 Claude Code、Codex 或 Cursor 做项目的开发者，尤其适合需要互相审 diff、接手会话的协作场景。目前 Beta 免费试用，浏览器里可先玩演示版。

怎么用

  1. 在代码所在的机器上跑起 Agent 会话
  2. 同事从自己电脑加入同一会话
  3. 读上下文、审 diff、批准下一条命令，或接管远程桌面
