Liquid AI d1.3-ultra——不聊天的决策模型登顶，专做判断不写字

Liquid 的 d1.3-ultra 不生成文本，只对给定选项返回校准概率，在决策指数榜单上拿到第一，专为分类、排序与打分任务而生。

有效 11-28 · 早 高热度 原始来源 ↗

Liquid 11 月 27 日发布了 d1.3-ultra，一个不聊天的模型：它不生成文本，只对给定的选项返回校准概率，专门做判断。在 Artificial Analysis 的决策指数上，它拿到 76.4 分，在 27 个模型中排第一。

先看这几点

  • 不生成文本，一次返回每个选项的校准概率，定位就是决策而非对话。
  • 决策指数 76.4 分，27 个模型中第一；四舍五入后与 Bison 31B 并列，未四舍五入领先 0.5 分。
  • 新增排序、图片与音频取值、音频时间定位三项能力。
  • 托管 API 每百万输入 tokens 0.042 美元，控制台已上线；未开源权重。

大多数模型都在比谁写得好，这个模型反其道而行之：把“选哪个”这件事单独做精。对分类、排序、打分、风控、推荐这类任务来说，直接输出概率比让语言模型写一段话再解析要干净，也更容易接入自动化的决策流程。76.4 分的榜首位置说明这条路线的上限不低，但榜单分数终究只是参考，关键还是看它在你自己的任务上准不准。

适合做分类、排序、审核、推荐与评估系统的开发者，以及需要把模型判断接进业务流程的团队。对只是想找一个聊天模型的人来说，这个模型并不对口，选它之前先确认自己的任务确实是“做判断”而不是“写内容”。如果团队已经在用大模型做判断，可以先拿一小批历史样本做对照测试，再决定是否替换现有方案。

怎么用

  1. 先确认任务形态：选项是否明确、是否需要概率而非文本。
  2. 用托管 API 的控制台做小规模测试，对比现有方案在同一批样本上的表现。
  3. 留意 OpenRouter 与 Vercel 接入仍在“即将推出”阶段，现阶段以官方控制台与托管 API 为准。
别忽略这一条

权重未开源，OpenRouter 与 Vercel 接入尚未上线；定价按每百万输入 tokens 0.042 美元计费，实际成本取决于调用量与输入长度，上线前先做小规模成本测算。
