Sandscale——免费的 Agent 云沙箱：每月 100 小时 awake 算力，暂停闲置不计费

给编程 Agent 用的 Firecracker 微 VM 沙箱：免费档每月 100 个 awake 小时，暂停与工具调用间隙的闲置时间不计费，超量也不自动扣费。

有效 11-26 · 晚 高热度 原始来源 ↗

Sandscale 是 11 月 16 日注册的新服务，面向编程 Agent 的云算力：沙箱、工作区与构建机都跑在它自己的 Firecracker 微型虚拟机上，通过一个 API 调用。Agent 在里面跑代码、改文件、跑测试，跑完可以暂停、快照、恢复，不用自己搭服务器，也不用把密钥和代码留在本地机器上。

先看这几点

  • 免费档每月 100 awake vCPU-hours，同时最多 3 个盒子
  • 5GB 存储、1 个工作区，单盒子最多 2 vCPU、单次最长 4 小时
  • 暂停与工具调用间隙的闲置时间不计费
  • 超量不自动扣费，新盒子等下月再开
  • 免费档也带 Vault 密钥管理、审批与审计日志

计费方式是它最值得留意的地方。多数云沙箱按墙钟时间或启动时长收费，Agent 等待工具返回、等你确认的那段时间也在烧钱。Sandscale 只计盒子醒着的时间，暂停和空闲不计费，这让 100 小时变得耐用得多：一次几十分钟的改代码任务，实际 awake 时间可能只有十几分钟。按这个算法，免费档足够支撑日常的小步验证，而不是点两下就没了。

适合让 Claude Code、Codex、Gemini CLI 这类 Agent 在隔离环境里跑代码的人：做开源项目、跑不信任的仓库、并行开多个任务，或者电脑配置一般、不想让 Agent 直接动本机文件。个人开发者先拿免费档验证流程最划算，团队则可以看它的策略与审批能力再决定。

怎么用

  1. 注册免费账号，进入控制台
  2. 按文档用 API、TypeScript SDK 或 MCP 接入你的 Agent
  3. 给 Agent 开一个盒子，设好模板、规格与审批规则
  4. 跑完暂停或快照，需要时再恢复继续
  5. 在仪表盘里看审计日志与剩余 awake 小时
免费档的边界

单盒子最多 2 vCPU、单次最长 4 小时，100 小时用完后新盒子要等下月。付费档超量是每 awake vCPU 小时 0.05 美元，可以开关。跑长任务前先估算 awake 时间，别把大构建拆成多次短跑，中间的唤醒与环境准备也会吃额度。

这是个很新的服务，节点目前在美国东部，欧洲节点还在准备中。先用免费档跑一两个真实任务，确认延迟、网络策略与审批流程合用，再决定要不要升级到 Pro。
