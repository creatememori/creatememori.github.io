Doodle——Windows 任务栏上的火柴人 AI 助手：提问、口述打字，还会自己写插件

住在 Windows 任务栏上的小火柴人助手：随时提问、口述打字进任意应用，还能在沙盒里现写插件，点头后才启用。

有效 11-26 · 晚 高热度 原始来源 ↗

Doodle 是 11 月 25 日上线的一款 Windows 小助手，形象是一个住在任务栏上的小火柴人。按 Ctrl+Shift+Space 随时提问，面板会浮在当前窗口上方；按 Ctrl+Alt+Space 可以口述，话直接打进正在用的任意应用，语音识别在本机跑。英文说句话就能设提醒，比如二十分钟后提醒把面包拿出来。

先看这几点

  • Ctrl+Shift+Space 随时提问，不用切窗口、不用另开标签页
  • Ctrl+Alt+Space 口述打字进任意应用，识别在本机跑，还会记住纠正过的词
  • 用英文说句话就能设提醒，另有 Doodle Studio 可以做 3D 场景、图表与 live board
  • 不会的功能它能在沙盒里现写插件，列清权限，等你点头才启用

它有意思的地方不在“又一个聊天框”，而在两点：一是它住在任务栏上，帮忙不需要切换上下文；二是它会“进化”，遇到不会的事不是直接拒绝，而是先在沙盒里写个插件，把插件能碰什么列清楚，等你点头才启用。同一个需求提三次，它还会主动问要不要合成一步操作。

适合整天待在 Windows 上、又不想总在应用之间切来切去的人。经常要口述输入、记临时提醒，或者希望助手按自己的用法慢慢长出新功能的人，可以拿它当主力助手试一段时间。

怎么用

  1. 去官网装好 Doodle，确认它出现在任务栏上，免费起步
  2. 按 Ctrl+Shift+Space 提一个正在手头的问题，看看回答能不能直接用
  3. 按 Ctrl+Alt+Space 口述一段话进记事本或聊天框，检查识别准不准
  4. 提一个它不会的功能，看它怎么在沙盒里写插件、列权限，逐条看清再点头
  5. 同一个需求出现第三次时，留意它会不会主动提出合成一步操作
别忽略这一条

Doodle 目前是 Windows 专属，Mac 用户先别装。提醒的例子目前是英文说法，中文怎么说、准不准要自己试一次。插件哪怕是它自己写的，也要逐条看清权限再点头，别图省事一路确认。免费起步，长期价格以官网口径为准。
