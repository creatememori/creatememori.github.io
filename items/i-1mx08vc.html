Fraunces——Undercase Type 的可变衬线字体 specimen 站

Undercase Type 的可变衬线字体 specimen 站：SOFT、WONK 等四个轴随便拨，从端正一路玩到歪歪扭扭，排版本身就是示范。

有效 11-26 · 晚 中热度 原始来源 ↗

Fraunces 是 Undercase Type 为自家可变衬线字体做的 specimen 站。它最迷人的地方是四个轴：光学尺寸、字重、SOFT 与 WONK，随便拨一拨，同一款字体能从端正严肃一路玩到歪歪扭扭。站内排版本身就是示范：标题、段落、字号对比，全用 Fraunces 自己排出来。

先看这几点

  • 四个轴：光学尺寸、字重、SOFT、WONK
  • 9pt、72pt、144pt 三档字号展示，大小通吃
  • 站内附讲 wonky 老式字体复兴的文章
  • 排版本身就是示范：标题与段落都用 Fraunces 排出来

Fraunces 的来历写在站内文章里：2018 年 Google Fonts 请 Undercase Type 补一款展示字体，他们盯上了 Cooper Black、Windsor 那类被叫做 wonky 的老式字体，源自 19 世纪末工艺美术运动，70 年代又被设计师翻出来反叛正统。站内文章把这段历史讲得很清楚，读完再拨 WONK 轴，就知道它在玩什么。

适合想给标题找点个性的设计师与前端，也适合对字体文化感兴趣的人。展示标题、播客封面、活动海报这类需要性格的场合，它比中规中矩的衬线体更出挑；长正文则建议先看 9pt 小字号的表现再决定。

站内字号展示分 9pt、72pt、144pt 三档，分别对应正文、标题与超大展示，小字号下字体的骨架是否还站得住，一眼就能看出来。光学尺寸轴就是为这件事准备的：字号越小，笔画与间距的补偿越明显，调轴时值得单独留心。

怎么用

  1. 打开 specimen 站，先拨 SOFT 与 WONK 轴，看风格变化
  2. 在 9pt、72pt、144pt 三档之间切换，确认大小字号都合用
  3. 读站内 wonky 字体文章，了解这款字体的来历
  4. 定下轴值组合后，记下来再去找授权与下载入口
提示

WONK 轴是这款字体的灵魂：数值拉高后字母会带点歪斜与俏皮，标题用着出彩；但别全站都拉满，标题歪、正文正，对比着用效果最好。

别忽略这一条

这是字体 specimen 站，不是下载站：站内主要用来试排与读文章，拿字体文件与确认授权要去发行渠道。商用前先确认授权，别只凭试排页的印象直接用。
