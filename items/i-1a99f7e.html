Cinecode——一句话想法，AI 剧组给你拍出 10 分钟以上的电影

一句话想法，AI 剧组给你拍出 10 分钟以上的电影：Agent 写剧本、逐帧代码绘制画面、设计音效，不用视频生成模型、不耗 credits。

有效 11-27 · 中午 高热度 原始来源 ↗

Cinecode 是 MIT 开源项目：接 Claude Code 或 Cursor，输一句话想法，Agent 写剧本、逐帧用代码绘制画面、设计音效，拍出 10 分钟以上的电影。不用视频生成模型、不耗 credits，成本走自己的 Claude 或 Codex 订阅。

先看这几点

  • 一句话想法，AI 剧组拍出 10 分钟以上的电影
  • 逐帧代码绘制画面，不用视频生成模型
  • Agent 写剧本、绘画面、设计音效一条龙
  • MIT 开源，成本走自己的 Claude/Codex 订阅

它和“文生视频”走的是两条路：不靠生成模型逐帧幻想画面，而是让 Agent 用代码把画面画出来。好处是风格稳定、可控、能改——剧本与画面都是代码与文本，改一句提示词就能改一场戏；代价是画面质感取决于代码绘制的上限，更像动态绘本而不是实拍。

适合想用 AI 做科普动画、解说视频或短片实验的创作者，尤其适合已经在用 Claude Code 或 Cursor 的人：不用另买视频额度，订阅本身就是成本。

怎么用

  1. 从 GitHub 拉下 Cinecode，接 Claude Code 或 Cursor
  2. 输一句话想法，让 Agent 写剧本
  3. Agent 逐帧代码绘制画面、设计音效，成片后检查调整
别忽略这一条

Windows 端完整成片尚未验证，Windows 用户先跑一小段试试；成本走自己的 Claude/Codex 订阅，token 用量取决于片长与修改次数。

Cinecode 的制作方式是：MIT 开源，接 Claude Code 或 Cursor；Agent 写剧本、逐帧代码绘制画面、设计音效。不用视频生成模型、不耗 credits，成本走订阅。支持中文提示词与 4K。Windows 端完整成片尚未验证，Mac 与 Linux 上先试；AI 生成的画面与真实摄影仍有差距，别拿它拍纪实片。
