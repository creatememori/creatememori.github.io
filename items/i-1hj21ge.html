Hub by Icons8——一行命令指挥上百个 Claude Code/Codex 会话：只把要拍板的决定推给你

Icons8 的开源调度器：一行命令装好，在浏览器或 Telegram 里一句话指挥上百个 Claude Code 或 Codex 会话，只把真正需要拍板的决定推给你。

有效 11-26 · 晚 高热度 原始来源 ↗

11 月 24 日上线 Product Hunt 当日登顶的 Hub，是 Icons8 团队为自己造的调度器：一个 Claude Code 或 Codex 会话只擅长一次做一件事，十个并行就乱成一团。Hub 让几百个会话同时跑，协调器把任务分给各会话的 Agent，每个执行者独占一个 git 工作区，而你只需要在浏览器或 Telegram 里回答那些真正需要拍板的决定。

先看这几点

  • 一行命令装好，浏览器或 Telegram 里一句话派活，不用盯着每个会话。
  • Apache-2.0 开源、自托管，跑在自己的 Mac、Linux 或 Windows 上。
  • 每个任务独占 git 工作区，会话之间能互相读步骤与结果。
  • 结果附截图、视频或前后对比，还有另一模型先尝试反驳验证。
  • 实验性质：Agent 默认不经确认直接执行，先读仓库 SECURITY.md。

Hub 本身没有自己的模型运行时，它跑的是货真价实的 Claude Code 或 Codex 会话，靠协调器、消息总线与事件日志把它们管起来。掉线的会话会带着对话记录回来，忙碌会话的消息会排队等轮到它，两个 Hub 之间还能通过邀请互联、互相派任务。Icons8 自己的战绩是：从 9 月 29 日启用到 11 月中旬，546 个已合并请求、约 32 万行代码，其中 55% 是测试——数字来自他们自己的 GitLab，未必能复现到你的团队。

适合手头同时有几十个任务、又不想开几十个终端窗口的人：并行重构、批量修 bug、跨仓库的改动最能体现它的价值。客服、设计、SEO 这些非工程角色也能用 plain 话派活，但前提是得有一个 Claude 或 ChatGPT 订阅。只跑一两个会话的话，它反而是多余的中间层。

怎么用

  1. Mac 或 Linux 跑一行安装命令，Windows 用 PowerShell 的对应命令；不要以 root 运行。
  2. 装完打开本地页面，用自己的 Claude 或 Codex 账号登录。
  3. 先派一个小任务，看协调器怎么拆分、执行者怎么回决定卡片。
  4. 顺手后，再把成批的任务、常驻 Agent 与 Telegram 提醒接进来。
别忽略这一条

Hub 明确写着实验性质，且 Agent 默认不经确认直接执行：它带来的是秩序，不是围墙。贵重仓库建议先放在单独的机器或隔离环境里跑；模型费用是你自己的订阅，十个忙碌会话消耗额度的速度也差不多是十倍， routine 任务记得选便宜模型。
