有效 11-27 · 中午 高热度 原始来源 ↗

WhipDesk 让你在手机浏览器里看住编程 Agent：npm install -g whipdesk，扫码 30 秒连上，就能在手机上看 Claude Code、Codex、Cursor 等 Agent 的状态，卡住、跑完或崩了都会自动提醒。两端开源、端到端加密，局域网不用账号。

先看这几点

  • 手机浏览器看 Agent 状态，不用装 App
  • 卡住、跑完、崩了自动提醒
  • npm 一行安装，扫码 30 秒连上
  • 两端开源、端到端加密，局域网不用账号

让 Agent 在电脑上跑长任务，最难受的是不知道它卡在哪：回来看一眼发现它半小时前就停在等确认。WhipDesk 把这件事变成了手机通知——跑完了、卡住了、崩了，都推到手机上，人在外面也能知道什么时候该回去处理。

适合让 Claude Code、Codex 或 Cursor 跑长任务的开发者，尤其适合一边跑 Agent 一边做别的事的人。局域网内不用账号，数据不出内网。

怎么用

  1. 电脑上 npm install -g whipdesk
  2. 手机扫码，30 秒连上
  3. 手机浏览器里看 Agent 状态，等提醒即可
提示

提醒依赖手机浏览器保持连接；出门在外要跨网访问的话，先确认自己的网络方案，局域网模式只在同一网络内有效。
