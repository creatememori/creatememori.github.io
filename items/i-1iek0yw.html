Animama——免费开源的 AI 桌面伙伴：3D 二次元形象浮在屏幕角落陪你干活，会记事、会变脸

免费开源的 AI 桌面伙伴：3D 二次元形象浮在屏幕角落陪你干活，会记事、会变脸，记忆存在可编辑的 Markdown 文件里。

有效 11-28 · 早 高热度 原始来源 ↗

11 月 18 日上线、11 月 25 日登 Show HN，AGPL 开源。Animama 是一款免费开源的 AI 桌面伙伴：3D 二次元形象浮在屏幕角落陪你干活，VRM 形象 24 种情绪、300+ 手势动作，记忆存在可编辑的 Markdown 文件里，中文语音可用，Windows 11 与 macOS 均有安装包。

先看这几点

  • 3D 二次元形象浮在屏幕角落，24 种情绪、300+ 手势动作
  • 记忆存在可编辑的 Markdown 文件里，自己能看能改
  • 中文语音可用，直接用中文对话
  • Windows 11 与 macOS 均有安装包

桌面伙伴这类产品不少，但多数是黑盒：记忆存在云端、形象不能换、对话要走官方订阅。Animama 的不同在于把两件事交给用户：形象是标准的 VRM 格式，记忆是本地可编辑的 Markdown 文件。对喜欢折腾、想让桌面伙伴真正“记得自己事”的人来说，这种开放程度比多几个表情重要。记忆存在 Markdown 文件里还有一个实际好处：换电脑、换模型都不丢，文件拷走就能接着用；想删哪段记忆，直接改文件就行，不用在应用里翻设置。

适合喜欢二次元形象、想在工作时有个轻量陪伴的 Windows 11 或 macOS 用户，也适合想研究桌面 Agent 形态的开发者。注意应用本身免费，但聊天要接自己的 ChatGPT 套餐、API Key 或本地模型，按模型商计费；另外这是 18+ 应用，Windows 安装包未签名，首次打开 SmartScreen 会弹警告，属于正常现象。对创作者来说，它也可以当选题素材：桌面伙伴这个品类本身就有话题度，演示 24 种情绪与 300 多个手势动作，观众很容易看进去。

怎么用

  1. 在 GitHub 确认安装包对应自己的系统
  2. 安装后接自己的 ChatGPT 套餐、API Key 或本地模型
  3. 打开记忆用的 Markdown 文件，写几条想让它记住的事
  4. 试一次中文语音对话，确认情绪与手势表现
