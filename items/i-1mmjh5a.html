Cal Sans Text UI 2.020——Cal Sans 的界面专用切分：与 Inter、SF Pro 同占位，标签在按钮里光学居中

Cal Sans 的界面专用切分：与 Inter、SF Pro 同占位，按钮里的标签光学居中，现已并入 Google Fonts。

有效 11-27 · 晚 中热度 原始来源 ↗

Cal Sans Text UI 2.020 是 Cal Sans 的界面专用切分，11 月 26 日发布新版，24 日并入 Google Fonts 仓库。它是为界面排版做的版本：字重 400–700，带真斜体，GEOM 可变轴有四档，分别对应无障碍、界面、基础与几何四种形态。

界面字体的细节往往藏在对齐里。这个版本与 Inter、SF Pro 保持同占位，换字体不用重排版式；标签在按钮里是光学居中的，视觉上不会偏上或偏下。对于做产品界面的人来说，这类细节省下的是一次次手动微调的时间。GEOM 轴的四档切换也给了更多选择：同一套字体，无障碍场景与几何风格可以各取所需。

先看这几点

  • 字重 400–700，带真斜体
  • GEOM 轴四档：无障碍、界面、基础、几何
  • 与 Inter、SF Pro 同占位，替换不用重排
  • OFL 1.1 免费商用，npm 可装 @calcom/cal-sans-ui

怎么用

  1. 在 Google Fonts 仓库或 npm 上找到 @calcom/cal-sans-ui
  2. 按项目需要选字重与 GEOM 轴档位
  3. 替换现有界面字体，对照检查按钮与标签的对齐
  4. 确认 OFL 1.1 协议条款后上线使用
提示

先拿一两个核心界面做替换测试，确认占位与居中效果符合预期，再全量替换。

适合前端开发者、产品设计师，以及正在给产品挑界面字体的人。坑不多，但要留意：可变轴的四档形态需要在实际界面里逐档看效果，别只看字样表；新版刚并入 Google Fonts 仓库，引用方式以仓库里的最新说明为准。另外，GEOM 轴的四档形态值得逐一试一遍：无障碍档更注重可读性，几何档更有个性，界面档偏中性。同一套字体在不同场景下切换形态，等于一套字体覆盖了多种语气，长期维护一套字体也比维护多套更省事。如果项目里已经在用 Inter 或 SF Pro，替换成本很低，先从按钮与标签这类小地方换起，效果立即可见。先换一两个界面试试水，确认效果后再全量替换，稳妥又省事。
