CrossDesk——免费开源的轻量远程桌面：浏览器直接控电脑，不用在控制端装软件，Windows/macOS/Linux/iOS/Android 全平台，还能局域网直连、自托管

免费开源的轻量远程桌面：浏览器打开网页客户端、输 9 位设备 ID 就能控电脑，支持局域网直连与自托管，Windows、macOS 与 Linux 互控。

有效 11-27 · 晚 高热度 原始来源 ↗

CrossDesk 是本周 GitHub 涨星最快的远程桌面之一，约 8,700 星，GPL v3 开源，v1.7.7 在 11 月 23 日发布。它覆盖 Windows、macOS 与 Linux 互控，控制端不用装软件：浏览器打开网页客户端，输入 9 位设备 ID 就能开始控制。

先看这几点

  • 约 8,700 星，GPL v3 开源，v1.7.7 于 11 月 23 日发布
  • 浏览器网页客户端输 9 位设备 ID 就能控，不用在控制端装软件
  • 支持局域网 IP 直连，不用云端中继
  • 双窗格传文件、DeskHub 多设备同屏，新版还加了 MCP

它适合需要临时帮别人看电脑、或者在不同设备之间来回切换的人。浏览器即控的设计省掉了在控制端装客户端的步骤，借别人的电脑也能马上上手。局域网直连对内网场景很友好：同一网络下的两台电脑可以直接连，不经过云端中继。双窗格传文件与 DeskHub 多设备同屏，则是日常远程协助里最常用的两个功能。

新版加入的 MCP 值得留意：Agent 在授权后能直接操作远程电脑，这让它不只是人用的远程桌面，也能接进自动化流程。平台覆盖上，桌面端是 Windows、macOS 与 Linux 互控，移动端 iOS 与 Android 也在支持范围内。远程桌面工具最怕的是关键时刻连不上，CrossDesk 的局域网直连与浏览器直控等于给了两条路：内网走直连，外网走网页客户端，换一台电脑也能马上接手。先拿两台自己的设备试一次完整流程，确认延迟与文件传输都顺手，再用在正式场合。使用前先想清楚自己的场景：偶尔远程帮个忙，网页客户端就够了；长期固定使用，再考虑自托管。

怎么用

  1. 在被控电脑上装好 CrossDesk，记下 9 位设备 ID
  2. 控制端浏览器打开网页客户端，输入设备 ID 连接
  3. 同一局域网内可改用 IP 直连，不走云端中继
  4. 需要传文件时用双窗格传文件，多设备用 DeskHub 同屏查看
  5. 想自托管再按官方说明搭信令与中继服务
注意

免费开源；自托管需自己搭信令与中继服务。只想简单远程控制的话，直接用默认方式即可，不必一上来就自托管。
