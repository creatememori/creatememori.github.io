Type Thursday——全球字体爱好者月度聚会，边喝酒边点评字形

Type Thursday 是全球字体爱好者的月度聚会：2015 年从布鲁克林一家酒吧起步，现已遍布十余个城市，每月一小时 Type Crit 点评进行中的字体设计。

有效 11-28 · 早 中热度 原始来源 ↗

Type Thursday 2015 年从布鲁克林一家酒吧起步，如今已遍布纽约、伦敦、洛杉矶、米兰、巴塞罗那等十余个城市。每月活动先社交，再由主持人带队做一小时 Type Crit，点评进行中的字体设计；站上各城市页都用当地语言的 pangram 做试排。

先看这几点

  • 2015 年从布鲁克林一家酒吧起步，现已遍布十余个城市。
  • 每月活动：先社交，再由主持人带队做一小时 Type Crit。
  • Type Crit 点评进行中的字体设计，是新手最直接的学习场。
  • 各城市页用当地语言的 pangram 做试排，细节里见社区感。

字体设计是一门手艺活，光看书学不会，拿自己的字给别人点评才学得快。Type Thursday 的 Type Crit 就是为此存在的：每月一次，带着进行中的字体来，主持人带队点评，听别人被点评也能学到东西。从一家酒吧发展到十余个城市，说明这种“边喝酒边聊字形”的形式确实有生命力。对新手来说，听别人被点评往往比自己被点评学得更多：别人的问题，很可能也是你正在犯的错。

适合正在画字体、想找人点评的设计师与学生，也适合想进入字体圈子、认识同行的爱好者。所在城市没有分会时，可以先逛网站的城市页与试排，感受社区的组织方式。先从网站的城市页逛起，看看当地分会的活动形式，再决定要不要带作品去。

怎么用

  1. 先到网站找到离自己最近的城市分会，确认活动时间与地点。
  2. 带着进行中的字体设计去参加 Type Crit，提前准备好想请教的具体问题。
  3. 没有分会时，先看各城市页的 pangram 试排与活动记录，了解社区的运作方式。
先试再定

活动以线下聚会为主，时间与地点以各城市页为准；Type Crit 点评的是进行中的作品，带着半成品去比带着成品去收获更大。
