Video ShotCraft——124 张产品宣传片镜头配方卡：Agent 按卡拍片，还能卡着音乐节拍剪

一套给 Claude Code 与 Codex 用的 AI 拍片技能：124 张镜头配方卡配 150 个动效预览，Agent 按卡分镜、用 Remotion 逐帧渲染，交出可继续改的成片与源码。

有效 11-26 · 晚 高热度 原始来源 ↗

Video ShotCraft 不是视频生成器，而是一套让 Agent 帮你拍产品宣传片的技能：告诉 Claude Code 或 Codex 一句需求，它先抓你产品的真实截图，再按 124 张镜头配方卡分镜，用 Remotion 逐帧渲染，按音乐节拍剪辑并配上音效，最后交出 1080p 的 MP4 与全套可以改的 React 源码。

先看这几点

  • 124 张配方卡、150 个镜头，分开场、运镜、转场、字体、UI 入场等 10 类
  • 每张卡都有 Remotion 实现与在线画廊预览，挑中了直接按名字点菜
  • 成片之后还能在浏览器工作台里继续剪，改文案、换镜头、调速度都行
  • Apache-2.0 开源，仓库已有 2.2 万多星，另可导出剪映草稿接着剪

它值得拍，是因为它把“AI 拍片”从玄学变成了手艺：每一帧都是代码按你的截图和文案画出来的，字不会糊、品牌色不会跑偏，成片不满意还能打开源码改。观众最想看的不是参数表，而是同一张配方卡换到自己产品上会长什么样，视频里拿一个真实产品从头跑一遍最有说服力。

适合要给自己产品做宣传片的独立开发者与小团队，也适合接宣传片活的创作者。手里有现成产品页、想快速出一支能上线的片子，又不想把成片交给黑盒生成器的人，可以先拿它跑一支试试。

怎么拍成视频

  1. 标题方向：124 张宣传片镜头配方卡，让 AI 按卡拍片，还能卡着音乐节拍剪
  2. 先在画廊里挑三张卡，讲清“配方卡”就是一套写好的运镜与转场做法
  3. 拿一个真实产品跑完全流程：Agent 抓截图、分镜、渲染、按节拍剪辑
  4. 放出成片后打开浏览器工作台，改一句文案再导出，证明成片可以继续改
  5. 收尾讲清限制：剪映导出仅在 Mac 上验证过；Remotion 大公司用可能另需付费许可
别忽略这一条

渲染要装 Node.js 与 ffmpeg，低配 Linux 机器可能要加 --concurrency=1 这类参数。剪映导出目前只在 Mac 上验证过，Windows 用户先别承诺效果。Remotion 本身另有商用许可规则，公司项目用之前先看清条款。
