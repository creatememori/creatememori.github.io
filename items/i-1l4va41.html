Agentic Algorithm Engineering——让 Agent 按可证伪假设替你优化代码：KaHIP 提速 3.9 倍、VieCut 提速 8.9 倍

把算法工程方法做成 Claude Code 与 Codex 的技能：Agent 按“可证伪假设、实现、实测、保留或丢弃”的循环替你优化代码，提速结果逐项验算，每次会话还出一份逐假设的 PDF 报告。

有效 11-26 · 晚 高热度 原始来源 ↗

11 月 23 日登上 Show HN 的 Agentic Algorithm Engineering，来自一位大学教授：它把算法工程的方法论做成 Agent 技能，让 Agent 像性能工程师一样工作——先提一个可证伪的假设、写清预测效果，再实现、实测，达标就保留为补丁，不达标就丢弃。KaHIP 图划分提速 3.9 倍、VieCut 最小割提速 8.9 倍，且结果逐项验算无误。

先看这几点

  • 每次实验先有假设与预测，跑完再裁决，不靠“感觉快了”。
  • 每项被保留的改动都留下一个可审查的 Git 补丁。
  • 每次会话出一份 PDF 报告：每条假设一页，含直觉、预测与实测。
  • VieCut 提速 8.9 倍且每个割不变；KaHIP 提速 3.9 倍且划分质量不变。
  • MIT 开源，Claude Code 里 /plugin install aae 即装。

它和“让 Agent 随便改改看”的区别，在于正确性是先约定的：开始前先和你定好 benchmark、指标、正确性检查与预算，跑完每一步都拿断言验算。比如 VieCut 的会话里，每个割都和原输出逐一比对；KaHIP 的 537 次运行里，划分质量保持不变。被丢弃的假设也不会白跑，教训会沉淀进项目自带的知识库，下次会话能接着用。

适合手里有性能瓶颈、又不敢让 Agent 碰核心代码的人：图算法、数值计算、高性能计算这类“改错一点就全错”的代码最对口。只是想提速一段普通业务代码、或没有可靠 benchmark 的项目，它的前提条件就不成立，先补测试与基准再说。

怎么用

  1. Claude Code 里执行 /plugin install aae，装好后用 /aae:aae 说清要优化哪段代码。
  2. 先和 Agent 定好 benchmark 命令、指标方向、正确性断言与实验预算。
  3. 让它自己跑循环，结束后收补丁与 PDF 报告，逐条看假设页。
  4. 想出 PDF 报告，本机要先装 LaTeX；没有的话会话照常跑，只跳过报告。
别忽略这一条

项目较新，方法本身来自一篇待发表的论文，提速数字都是作者自己会话里的结果，换到你的代码上不保证复现。Codex 侧想无人值守跑循环，官方建议用 YOLO 模式——那会绕过审批与沙箱，只在可信的隔离环境里用。
